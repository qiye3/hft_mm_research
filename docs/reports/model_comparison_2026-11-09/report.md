# 2026-11-09｜统一模型对照与综合研究结论

## 当前结论

完成了531天数据上的25个模型对照。候选列只从训练期确定，各模型使用相同的600万训练秒、10万调参秒、完整验证和测试时间戳，统一填补缺失并隔离标签边界。按验证期调参样本MSE冻结的当前模型为199列完整输入组LightGBM。

它在完整验证期的IC为 **0.24265**、R²为 **5.885%**，历史测试IC为 **0.25029**、R²为 **6.239%**。当前结果支持三点判断。

1. 深度变化是当前输入池的重要组成部分。完整输入模型去掉深度组后，验证IC降至0.16611，92个验证日的IC均下降。
2. 扩展深度表达和过去序列都有增量。两者合并相对90列基线，日均IC提高0.00754，91/92个验证日改善。
3. 相同输入与训练样本下，LightGBM优于本轮线性和GRU设置。GRU加入30/120秒历史后有所改善，本轮最佳GRU的验证IC为0.22922。

2026年9—10月数据已被前期研究查看，本报告将其统一称为“历史测试”或“回看测试”。本轮选择依据来自训练和验证期，后续封存数据用于新的泛化验收。

完整输入组包含90列基线、40列深度候选、9项深度比率和60项历史派生，共199列。历史派生为12个训练期选定输入的1/5/30秒滞后及30/120秒均值偏离。深度比率使用买卖深度变化差除以两侧变化绝对值之和，分母下限1e-6。表中输入列数未计缺失通道，模型实际接收的通道数为其两倍。

各模型使用相同训练行集。LightGBM比较31/127叶、最多1200轮并早停，GRU为hidden=64、1个epoch、batch=1024。GRU结果对应本轮固定训练预算。

## 5. 如何合并理解已有结果

此前报告中的三个问题已修正。

- A1的OBI零残差来自对OBI自身回归。新的七列共同训练样本回归显示，OBI对其余六列回归后仍保留54.94%的方差。控制OBI后的净深度残差IC约0.1207，两项结果分别描述不同方向的条件关系。
- 旧M4、M5、M6的验证行数分别为6,236,309、3,600,714、72,082，原逐组成绩混合了样本变化。低覆盖状态因子的验证缺失率97.30%，源于历史价差标准差为零时公式无定义。本轮按训练覆盖门槛选列，再统一填补，保留共同标签样本。
- 日IC表现聚类、数值相关与模型消融回答不同问题。638个日IC簇或16个探索代表用于描述表现结构，独立信息维数仍需模型增量研究。

同目录01—05报告中的information_validation实验另行保留。A2显示价格历史加入OBI后的验证R²从0.006262提高到0.014957；加入净深度的线性模型在少数日期明显退化。C实验在其共同100万训练秒条件下，树模型验证R²为0.064887、Ridge为0.009069。25日B1增加100ms秒内路径后，验证R²从−0.007375提高到0.000902，9个验证日均改善。

这些实验与本轮在候选输入、训练抽样、精度和clip设置上有差异，其数值在各自实验内比较。共同判断是保留OBI与深度，继续利用已有信息中的条件关系和历史路径。成交类变量在部分设置中提供条件区分，模型增量应结合对应的相同样本实验。

旧GRU复算的历史测试IC为0.271446、R²为0.073123，高于本轮完整输入模型的对应数值。旧模型的输入、搜索过程与训练设置不同，继续作为历史模型记录保留。旧90列模型用过Test IC选列，其成绩作为探索记录保存。当前模型选择依据为本轮冻结的共同口径比较。

正式因子共1236项。至少50个有效历史测试日的数量依预测周期为1s 1198项、10s 1189项、60s 1178项、180s 1171项、300s 1166项。因子覆盖门槛与模型共同样本数分别记录。

## 6. v4内存问题的处理与实测

旧v4/v6在全量矩阵复制和扩展时发生OOM。本轮按日生成共享磁盘矩阵，最多预读4天，按顺序携带120秒跨日历史。模型分块读取，线性使用Float64充分统计，树模型分块写训练映射，GRU按批次生成过去序列。正式Factors保留Float64，模型矩阵缓存使用Float32。

本轮在10 vCPU、60GiB内存、RTX3090 24GiB服务器上完成，缓存约36.24GiB。数据准备耗时19.18分钟，全链路耗时约115.3分钟。

| 测量项 | 实测 |
| --- | ---: |
| 数据准备进程树峰值匿名内存，定时采样 | 3.15GiB |
| 完整输入树训练进程树峰值匿名内存，定时采样 | 2.09GiB |
| 容器整体峰值匿名内存，定时采样 | 4.06GiB |
| 数据准备Peak RSS，GNU time | 23.32GiB |
| 全链路最大单任务Peak RSS，完整输入树训练 | 43.86GiB |
| 全链路平均CPU利用率，占10 vCPU配额 | 58.2% |
| 本轮新增OOM kill／内存中止 | 0／0 |

RSS包含已驻留的文件映射页，匿名内存反映实际分配，两项分别保留。任务设有匿名分配上限和全局准入余量，可回收文件缓存单独识别。全部训练和评价完成，逐行预测仍保存在服务器共享盘。已独立逐块核对冻结模型的验证／测试预测时间戳，并复算IC与MSE，与正式报告一致。本轮此前失败的临时矩阵已清理，释放约13.17GiB。
