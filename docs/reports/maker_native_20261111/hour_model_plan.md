# 一小时预测目标实验｜2026-11-13

当前原生Maker开发回放继续运行。本轮并行补充3600秒预测目标，检验30分钟和2小时之间的预测尺度是否改善费用后交易机会。复用既有训练输入与切分，不重新计算因子，不调整正在运行的Maker规则。

## 固定配置

- 模型配置：`config/models/cost_h3600_20261113.yaml`。入口为`run_cost_classifier.py train --horizon 3600 --side 1/-1 --seed 17`。
- 输入：冻结的146列原因子、16列现货信息、18列慢状态，以及各自缺失标记，共360列。训练截至2026-03-22，内部拟合与校准行沿用原划分；按3600秒目标剔除跨边界标签。
- 模型：买卖方向分别训练XGBoost费用后获利分类器，深度4、min_child_weight=50，其余参数沿用原模型。仅训练两个方向，不扫描种子或树深。
- 模型输出：`workspace/results/cost_h3600_20261113_v1/`。沿用训练期盈亏幅度和内部校准，将概率转换为预期净收益bps。
- 策略配置：`config/strategy/account_h3600_20261113.yaml`。一小时模型单独使用，以及与原30分钟模型等权组合，各比较固定持仓1小时、2小时，共四例。每次0.10BTC，10000USDT本金，Taker5bps和实际资金费，按到达十档盘口逐档成交。
- 策略输出：`workspace/results/account_h3600_20261113_v1/screening/`。先完成四例开发，按完整53天年化超过30%、实测敞口不超过1倍、去最好周仍盈利筛选；通过者冻结后才运行历史复核。模型生成复核预测不参与开发选择。

任务批次为`config/research/maker_native_queue/hour_models.yaml`，追加到现有队列。两个GPU任务通过依赖串行执行，沿用全局GPU锁，与事件转换共享内存准入。每个训练预约18GiB、匿名内存上限25GiB；任务失败由已有队列记录并重试，后续依赖任务不会使用缺失模型。

本轮仅扩展入口允许的3600秒参数，复用已有训练和交易代码。冻结输入已确认可读取，真实训练及回测结果待后台完成。
