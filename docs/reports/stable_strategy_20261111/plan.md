# 收益稳定性实验｜2026-11-11

本轮目标是改善跨月份、跨周及不同波动环境下的费用后收益。上一轮候选保持不变作为基准：30分钟费用分类信号、2小时持仓、每笔0.002 BTC。其历史复核收益主要来自六月，本轮不能只按总收益选择。

## 固定实验范围

输入继续使用冻结的360列模型输入：旧因子、现货信息、较长时间的市场状态及缺失标记。Train截至2026-03-22；开发为03-23至05-14；历史复核为05-15至07-06。此次不更改数据分区，复核属于已使用过的历史研究。

比较八组信号：原30分钟费用分类、三个固定种子的等权价值组合、2小时费用分类、30分钟与2小时同方向正价值共识，以及两种连续收益训练方法各预测30分钟/2小时。连续收益模型分别对买卖方向训练，共八个GPU模型。方法为Pseudo-Huber稳健损失，以及仅在拟合样本中将标准化目标截到±3后使用平方损失；验证和收益回放保留全部尾部行情。两种稳健模型的输出是稳健价值评分，不保证等于无偏条件均值。

每组信号比较三种退出规则，共24个开发案例：

1. 固定7200秒持仓。
2. 至少持仓1800秒，之后同方向正价值消失即退出，最长7200秒。
3. 入场时冻结风险尺度`max(20bps, 2×过去600秒实现波动)`。标记收益跌至负2倍风险尺度时止损；最高标记收益达到正2倍后，回吐1倍尺度时退出；最长7200秒。完整事前波动缺失时不开新仓。

所有策略继续使用既有逐档快照执行和现金账本，主动开平各5bps，另计资金费。策略管理只读取决策时可见的本地盘口，撮合使用订单到达时盘口；退出请求在部分成交后保持到真正空仓。每个区间账户连续跨日，末端停止新增仓位并实际平仓。波动保护触发指标计开平费用，不含持仓累计资金费；最终收益账本包含资金费。

## 选择与评价

先完成全部开发案例，再冻结选择，最后读取复核收益。候选需开发净收益为正、去掉最好一周仍为正、至少20笔往返和10个有权益变化的交易日。按最差月收益、去掉最好周收益、最大回撤排序保留前三例，另保留原候选基准。活动日包含持仓估值变化，不等同于新增交易日。

日收益来自完整连续账户的UTC日末权益差，包含无成交日期；周/月按UTC日历汇总。边界月和周可能不完整，比较仅限相同区间。报告总收益、最差周/月、去最好周、回撤、正收益周比例、交易数量，并保存完整亏损案例。上述门槛只是本轮筛选条件，不等同于已经通过长期稳定性标准。

先用快照执行筛选。若出现跨月和尾部表现均改善的候选，再安排原生事件回放；不能将快照结果称为原生结果。不同规则会改变实际入场机会，不能把规则间总收益差直接解释为同一批交易的退出改善。
