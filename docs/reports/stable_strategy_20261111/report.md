# 收益稳定性实验结果｜2026-11-11

本轮完成8个新GPU模型、24个开发策略案例及3个冻结历史复核案例。找到一个回撤和周度集中度较低的候选，但尚未解决跨月份、跨波动环境盈利的问题。

研究继续使用Train截至2026-03-22、开发03-23—05-14、历史复核05-15—07-06。每笔0.002 BTC，主动开平各5bps，另计资金费。下述结果均为到达时十档快照执行估计，不能替代原生事件回放。

## 为什么还不能说跨环境稳定了

组合退出候选历史复核的收益全部来自六月：五月0、六月4.3915、七月0。有权益变化的日期只有9天，九个日历周里只有两个正收益周。最差月为零来自没有交易，不能解释为在多个市场环境都盈利。

该候选26笔往返中，17笔能计算完整事前波动，全部属于训练期分界下的高波动组，净收益3.8347；另9笔因窗口不完整归入unknown，净收益0.5568。没有低/中波动交易的实证。多头22笔贡献6.2218，空头4笔亏损1.8302。

跨周期共识也没有创造互补收益：14笔复核交易全部为多头，去掉最好一周后亏损扩大到3.2814。

结论是：当前组合改善了部分交易的退出路径，却没有产生足够不同的入场机会。后续应该研究不同信息源或模型分歧如何影响入场，而不是继续只调整止损幅度。

## 失败方向及原因

1. 频繁退出增加了交易成本。2小时分类信号配合信号退出，在开发期有857笔往返，费用前盈利18.6527，手续费125.7003，费用后亏损106.9248。更频繁响应信号不等于更有效执行。
2. 波动保护没有改善原候选的开发表现：净收益由5.4831降至3.5655，回撤由4.4368升至4.8707。规则同时改变后续入场机会，不能把全部差异简单归结为某一笔止损。
3. 连续价值模型没有形成更好的候选。两种截尾平方损失模型以及2小时Huber模型，在开发区间双方向最大预测都小于零，没有交易；最佳早停均为一棵树。不是执行失败，而是这一训练目标和早停口径没有产生正价值评分。
4. 30分钟Huber保留19棵树，只产生少量多头机会。固定持仓开发净收益1.6830，但去掉最好一周为-0.6332，未通过稳定性选择。

### 本轮保留的结论与下一步

保留原候选作为原生已验证基准，保留等权组合＋信号失效退出作为较低周度集中度的研究候选。后者仍集中六月，没有充分理由升级为跨环境稳定策略。

下一轮优先改变交易价值估计，而不是继续微调止损。当前费用分类器把获利概率乘以全训练期统一的平均盈利/亏损幅度；不同波动环境的盈利、亏损与费用覆盖能力可能不同。应在训练期内按事前市场状态估计这些幅度，再冻结到后续区间比较，并安排相同持仓时间与方向暴露的择时对照。状态划分、收益幅度估计和入场门槛均只能使用训练数据，不能按照六月盈利反向定义状态。

这项机制仍是待检验假设，本轮没有运行状态条件价值模型。现有GPU队列与两轮CPU队列均已完成，没有留下需要人工盯守的运行任务。
