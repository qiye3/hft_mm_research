## 构造方式

本批命名为 **Gen041｜长周期微观结构压力与短长背离**，针对未来1800秒（30分钟）的费用分类任务。先保留现有 `intraday_20261111_v1` 的60/300/900/1800/3600/14400秒收益、波动和价格偏离18列，不重复构造价格/波动率因子。本批只使用BTCUSDT永续既有十档L2快照与Trades，不要求现货、ETH、Mark/Index、强平新数据。

共 **36 个Factors**：九个经济含义不同的基础信号，各取三档长历史窗口，共27个；再构造九个最近60秒与长期状态差/比，共9个。1秒整秒输出，先构造无未来数据的1秒中间统计，再在真实秒尺度上滚动；窗口缺口要保留真实时间位置。该批不使用OFI，若后续接入已实现但尚未默认登记的逐事件OFI，可在独立实验中单独验证其增量。

特别注意：压力、成交与买卖深度的窗口统计并不是对100ms比值直接求均值。成交失衡先累加买卖量再相除，深度变化先分别累计正负变动再求占比，报价/执行成本才使用逐秒均值。这些定义能够避免低成交量秒与高成交量秒被赋予相同权重。

### 使用到的变换和算子

#### 外层算子

| 算子名称 | 计算方式 |
|---|---|
| `_mean_Ws` | 在过去W秒有效整秒上计算算术均值，窗口为实际秒数，至少80%预期秒有效；用于OBI。 |
| `_signed_ratio_Ws` | `sum(d_s) / sum(abs(d_s))`；d为1秒买卖净深度变化。分母0时输出0且需记录活动量为零；不对逐秒比值再平均。 |
| `_down_share_Ws` | `sum(max(-d_s,0))/sum(abs(d_s))`；分别计算买、卖侧深度下降比例。若全部已知且无变化，输出0。 |
| `_qtyimb_Ws` | `sum(B_s-S_s)/sum(B_s+S_s)`，先加总成交数量再相除；有数据且整个窗口无成交取0。 |
| `_agree_mean_Ws` | 对每秒`sign(买卖主动成交量差)×sign(盘口失衡)`计算均值，0表示中性/无方向状态。 |
| `_mean_cost_Ws` | 窗口内有效整秒的`C_buy_25k-C_sell_25k`（bps）算术均值。 |
| `_p10_Ws` | 窗口内十档可见名义深度（USDT）的第10百分位。 |
| `_diff_60s_Ls` | 同一基础变量、同一统计定义的最近60s状态减去过去Ls状态，不做单位不一致的相减。 |
| `_ratio_60s_3600s` | `(P10_60s/P10_3600s)-1`；分母须大于0。 |
