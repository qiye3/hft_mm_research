# Gen041｜1800秒预测与费用分类增量实验计划

## 研究问题

本批重点验证：在已经有`intraday_20261111_v1`长历史收益、波动、价格状态18列的条件下，300—3600秒微观结构压力及其60s短长变化是否增加1800秒费用分类的预测和交易价值。研究假设：长期压力水平描述环境，60s相对长期变化描述压力转折，低深度分位描述易受冲击的市场状态。假设均待验证。

## 实施顺序

1. **核对真实输入**：导出`cost_classifier_20261111_v1/config.json`对应的最终模型输入列与数据版本。配置引用`intraday_20261111_v1`不等于18列全部入模。列清单应同时记录缺失率、训练/验证共同样本及所有窗口对齐。
2. **生成1s中间统计**：产出完整整秒时间网格、盘口有效状态、买卖100ms→1s成交量、L10双侧深度、深度的1s有符号变化、1s小单成交量、1s盘口与成交方向一致性、25k两侧理论执行成本、显示名义深度。先用10秒手算样例和跨午夜样例核对，再分天构建。
3. **生成27个长历史+9个短长差因子**：严格按《基础命名与原始字段对照表》，保持1s输出Float64，原始缺失位置不补0；缺失窗口不跨质量边界。若计算跨天需要预热历史，只能读取过去的历史，不能读取将来。
4. **确定共同样本**：E0—E4均在同一训练、验证日期和标签样本上比较；额外记录因新因素缺失导致的样本损失。训练期筛选、验证期选参，未参与选择的未来日期作为最终封存集。
5. **模型比较**：保留原费用分类任务及类别定义、采样权重、手续费、阈值和训练方法；如有多类别，使用对应多分类LogLoss与Brier评分。结果按日保存配对预测，不仅输出总体均值。
6. **回放**：冻结模型和策略参数后，在一致的持仓上限、交易费用、成交与退出规则下比较费用后收益、交易次数、最大回撤、单笔净收益、日度稳定性和剔除最好一周后结果。

## 五个对照模型

| 实验 | 输入组合 | 核心问题 |
|---|---|---|
| E0 | 现有1800s费用分类模型的**实际训练输入列** | 冻结基线 |
| E1 | E0 + 27个长历史微观结构因子 | 长期盘口/成交状态是否提供增量 |
| E2 | E0 + 9个60s对长期的差/比 | 短长状态变化是否比水平更重要 |
| E3 | E0 + 全36个Gen041因子 | 长状态与短长变化能否互补 |
| E4 | E0 + 仅在Train内部稳定筛选的Gen041因子 | 减少新变量噪声的结果 |

## 核心验收指标

| 指标 | 含义及判定方向 |
|---|---|
| `paired_delta_logloss` | 相同样本上，新模型LogLoss减去E0的LogLoss；**负值为改善** |
| `paired_delta_brier` | 概率Brier误差新模型减E0；**负值为改善** |
| `paired_delta_auc` | 二分类ROC AUC新模型减E0；**正值为改善**，多类时明确采用何种口径 |
| `calibration_by_bin` | 各预测概率桶真实事件发生率与预测率偏差，判断费用分类概率是否可信 |
| `paired_delta_ic` | 若另有1800s连续收益预测头，输出其Pearson IC变化；分类任务不机械替代分类指标 |
| `daily_delta` | 每个交易日对照预测误差与收益的差值，配对估计置信区间；可按周分块bootstrap |
| `net_pnl` | 费用后净收益，必须与E0用同一执行/持仓/退出规则 |
| `trade_count/max_drawdown` | 交易频次与最大回撤，避免通过极少数交易虚增单笔收益 |

## 时间泄漏与统计检查

- 1800s未来目标高度重叠。模型训练与验证的标签交界要隔离至少1800s；若实际持仓、退出或费用标签的观察期限更长，以最大实际观察期限为准。
- 特征lookback最长3600s，允许验证开始前读取训练期已经发生的历史作为预热，但不可在验证前反向拟定任何训练参数。
- 跨天和跨月保留完整历史时间戳，不因UTC日界清空长期状态；`DataQuality`断区必须阻止无效窗口穿越缺口。
- 60s和1800s、3600s滚动区间高度重叠，其差值是“短期对当前长期背景的偏离”；如需完全不重叠快慢状态，增设`(t-1800s,t-60s]`历史基线的单独对照。
- 固定已有`intraday_20261111_v1`中18列的实际入模列表；不得把同一长期收益/波动字段更名作为Gen041新增信息。
- 报告每个因子的有效率、零值率、分布、时间稳定性、与E0主要输入的相关性，最后用完整模型增量判断是否有独立预测价值。

## 推进/停止条件

优先观察E2相对E0、E1相对E0的同样本逐日改善。只有验证期的配对LogLoss/Brier至少一个稳定改善、概率校准没有恶化，且冻结策略回放的费用后表现不降低，才将对应因子送入下一版本的生产候选清单。对改进只出现在少数极端日期且交易机会并未改善的因子，保留研究记录而不继续扩窗。不要根据已查看的历史测试集反复微调本组公式。
