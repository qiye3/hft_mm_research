# Gen041｜基础命名、算子与原始字段对照表

本表是Gen041因子构造表中`计算方式（里层）`的唯一计算定义。W=实际历史秒数，所有滚动窗口为`(t-W,t]`；`s`表示不晚于整秒决策时刻t的可见数据。

## 原始字段字典

| 原始字段 | 含义与单位 | 数据来源 / 注意事项 |
|---|---|---|
| `bid_price_1…10` | 前十个可见买盘档位的报价（USDT/BTC）；1为最高买价 | L2快照，整秒时刻最新合法可见状态 |
| `ask_price_1…10` | 前十个可见卖盘档位的报价（USDT/BTC）；1为最低卖价 | L2快照，整秒时刻最新合法可见状态 |
| `bid_quantity_1…10` | 买盘前十档各价位的显示数量，单位BTC | L2快照，整秒时刻最新合法可见状态 |
| `ask_quantity_1…10` | 卖盘前十档各价位的显示数量，单位BTC | L2快照，整秒时刻最新合法可见状态 |
| `buy_volume` | 当前100ms桶主动买入的成交BTC数量 | Trades，100ms原始聚合 |
| `sell_volume` | 当前100ms桶主动卖出的成交BTC数量 | Trades，100ms原始聚合 |
| `Trades.price` | 逐笔成交价格，单位USDT/BTC | 原始Trades |
| `Trades.quantity` | 逐笔成交数量，单位BTC | 原始Trades |
| `Trades.aggressor_side` | 逐笔主动交易方向：buy为买方主动、sell为卖方主动 | 原始Trades归一化；如用is_buyer_maker，true代表卖方主动 |
| `Gen010 small-trade threshold` | 小额成交划分所用阈值及单位，必须读取Gen010实际冻结配置 | 配置参数，仅用于筛选逐笔Trades |
| `Gen012 25k sweep convention` | 25,000 USDT名义订单模拟吃盘方式、平均成本bps定义与缺档规则 | 配置参数，复用Gen012计算方式 |

## 九个基础变量与外层统计公式

| 里层基础名 | 完整公式与计算约束 | 原始字段 | 经济含义 |
|---|---|---|---|
| `book_obi_l1` | (bid_quantity_1-ask_quantity_1)/(bid_quantity_1+ask_quantity_1) | `bid_quantity_1、ask_quantity_1` | 盘口一档显示挂单压力 |
| `book_net_depth_direction` | 设 B_t=Σ_{i=1}^{10} bid_quantity_i(t), A_t=Σ_{i=1}^{10} ask_quantity_i(t), d_t=[B_t-A_t]-[B_{t-1s}-A_{t-1s}]; R_W=Σ_{s∈W} d_s/Σ_{s∈W}|d_s|。同价位不对齐，包含报价迁移造成的前十档组成变化。 | `bid_quantity_1…10、ask_quantity_1…10` | 买卖净深度变化的方向占比 |
| `book_bid_depth_down_share` | 设 B_t=Σ_{i=1}^{10} bid_quantity_i(t), b_t=B_t-B_{t-1s}; R_W=Σmax(-b_t,0)/Σ|b_t|。仅为可见前十档深度下降代理，不能认定为撤单。 | `bid_quantity_1…10` | 买盘显示深度减少在全部变动中所占比例 |
| `book_ask_depth_down_share` | 设 A_t=Σ_{i=1}^{10} ask_quantity_i(t), a_t=A_t-A_{t-1s}; R_W=Σmax(-a_t,0)/Σ|a_t|。仅为可见前十档深度下降代理，不能认定为撤单。 | `ask_quantity_1…10` | 卖盘显示深度减少在全部变动中所占比例 |
| `trade_aggr_qtyimb` | R_W=(Σbuy_volume_1s-Σsell_volume_1s)/(Σbuy_volume_1s+Σsell_volume_1s)，先汇总数量再求比值，禁止对各秒失衡简单取均值。 | `buy_volume、sell_volume（每100ms桶累计）` | 主动成交累计数量失衡 |
| `trade_small_qtyimb` | 按Gen010中已经冻结的小单规模阈值，在逐笔Trades中筛选后按主动买卖方向汇总成每秒B_small和S_small；R_W=(ΣB_small-ΣS_small)/(ΣB_small+ΣS_small)。 | `Trades.price、Trades.quantity、Trades.aggressor_side（或is_buyer_maker归一化）` | 小额主动成交累计数量失衡 |
| `cross_trade_book_sign_agree` | 先定义每秒 T_s=sign(buy_volume_1s-sell_volume_1s), O_s=sign(book_obi_l1_1s)；G_s=T_s×O_s，任一侧为0则G_s=0；R_W=mean(G_s)。取值[-1,1]。 | `buy_volume、sell_volume、bid_quantity_1、ask_quantity_1` | 主动成交压力与盘口压力的方向一致程度 |
| `book_exec_cost_gap_25k` | 由每秒最后有效的前十档盘口，按Gen012固定模拟规则计算25k USDT市价买入执行成本C_buy和卖出执行成本C_sell，均为bps；R_W=mean(C_buy-C_sell)。任何一侧无法在十档内完成则该秒为空。 | `bid_price_1…10、bid_quantity_1…10、ask_price_1…10、ask_quantity_1…10` | 25k USDT理论买卖主动执行成本差 |
| `book_depth_notional_p10` | D_s=Σ_{i=1}^{10}(bid_price_i×bid_quantity_i+ask_price_i×ask_quantity_i)，单位USDT；R_W=Q_0.1({D_s:s∈(t-W,t]})，取实际有效秒的第10百分位。 | `bid_price_1…10、bid_quantity_1…10、ask_price_1…10、ask_quantity_1…10` | 十档可见名义深度的历史低分位水平 |

## 1s中间表与数据质量规则

1. 时间和标签：每个UTC整秒t只使用在其决策时刻已可见的数据，交易所事件时间+20ms是既定模拟可见性假设。所有在t之后到达的更新不得回填。当前窗口和历史窗口都不能向未来插值。
2. 盘口：每秒最后一份有效L2快照用于十档深度、理论执行成本和价格；每秒的`OBI_1s`采用该秒内十个100ms有效位置的算术均值，至少8个有效位置。盘口超过现有年龄/连续性质量阈值的时间段为空。
3. 深度变化：`B_s`、`A_s`为连续可见整秒终点的前十档数量总和，`d_s`必须同时具有s与s-1s的有效快照；不跨数据缺口和质量区段。前十档价格移动引起的成分变化仍在该代理中，不能说是精确撤单。
4. Trades：100ms的buy/sell累加为每秒真实成交量。若该秒任意100ms成交数据流存在未知缺口，则整秒成交量为空，不能用零代替；已知完整但零成交的秒填0。对小单按Gen010已冻结的交易规模阈值筛选，阈值不能在Validation/Test重估。
5. 窗口有效性：长窗口的有效整秒数量≥80%预期长度；对`sum(B)/sum(S)`和`sum(d)`使用有效秒的实际累加值，不能用观测数比例把缺失成交量放大。对`OBI`、执行成本和深度低分位按有效秒统计。无活动且分母为0输出0的情况，须额外输出`zero_activity`质量日志，不能误认成某方向压力。
6. 缺失与回放：小额成交阈值和25k吃盘算法与现有Gen010/012保持完全一致。若10档内无法全部吃完规定名义金额，成本指标为null。建议每日期间至少回读3600秒的纯历史预热，跨日统计连续，严禁用当天0:00重置长期滚动状态。
7. 物理性能：窗口长度300/900/1800/3600秒，1s级计算应使用滚动和、计数和分位数结构（如流式平衡树/支持滚动删除的分位数器），不要对整段531天的100ms表重复扫描3600s窗口。第10百分位应对完整1s观测计算，不要拿分段分位数再平均。

## 算子输出及命名

长窗口名称在基础名中已经包含算子时，不再重复算子词；短长差在同一基础变量的短、长输出之间构造`_diff_60s_<L>s`；低分位相对变化为`book_depth_notional_p10_ratio_60s_3600s`。所有数值采用Float64，无统一后续标准化；如需Winsorize/标准化，必须仅由训练期拟定参数并记录为独立模型处理步骤。
