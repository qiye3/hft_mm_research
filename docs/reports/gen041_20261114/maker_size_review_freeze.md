# Maker扩大仓位候选的历史复核冻结规则

本规则在0.125BTC开发期原生回放完成前确定，不读取该候选历史复核收益。历史区间此前已被其他实验查看，称为历史复核，不称为新封存样本。

候选固定为旧1800秒费用分类模型cost_classifier_20261111_v1及其既有信号，原生directional_maker模式，单次0.125BTC，最长持仓1800秒，Maker减仓等待30秒，随后撤单确认再IOC。队列模型risk_adverse；决策间隔100ms、预测延迟1ms、订单进入延迟1ms、回报延迟0.5ms。Maker 2bps、Taker 5bps，使用实际资金费。参数来源config/strategy/maker_30m_size_20261114.yaml与cost_native.py的原生配置生成逻辑。

开发期2026-03-23至05-14、本金10000USDT。只有完整原生账本满足以下全部条件，才进入复核：

- 53个完整日历日的费用与资金费后账户年化严格超过30%。
- 账本实际最高总敞口不超过1倍，不能因入场时通过资金检查而替代该条件。
- 剔除最好周后的账户净收益为正。
- 所有计划区间回放完成，期末平仓，费用与资金费可由实际账本核对。

若通过，历史复核固定2026-05-15至07-06，单独以10000USDT起始本金运行相同参数。不得因复核结果改仓位、持仓、信号阈值、随机种子或删除亏损日期。复核仍要求年化严格超过30%、实际最高总敞口不超过1倍；月度、波动状态及剔除最好周结果独立报告，空仓月份不称为稳定盈利。

任一开发门槛失败，则保留结果、不运行本候选复核。任一复核门槛失败，则记录候选失败，不选择另一个复核赢家。本轮最终目标还要求改善跨月和跨波动环境集中度，不能仅凭年化门槛宣布全部完成。
