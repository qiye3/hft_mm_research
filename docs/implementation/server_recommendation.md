# 2026-11-05 — 服务器推荐配置与费用估算

## 一、当前推荐

当前研究以 C++ 行情回放、数据转换、盘口特征计算、线性模型和 LightGBM 为主。建议先使用 Linux CPU 环境，按交易日运行独立任务。CPU 核数主要用于同时处理多个日期，内存用于转换和训练，SSD 用于压缩文件读取、标准化分片和特征缓存。

| 使用阶段 | CPU | 内存 | 数据盘 | 使用方式 |
| --- | --- | --- | --- | --- |
| 单日验证与小规模研究 | 8 vCPU | 32 GB | 300 GB SSD | 同时运行 1—2 个日期任务，先完成 7—30 天研究 |
| 正式研究，推荐配置 | 16 vCPU | 64 GB | 500 GB SSD/NVMe | 初始设置最多 4 个独立日期任务，训练时单独安排资源 |
| 较大训练窗口或大量参数组合 | 32 vCPU | 128 GB | 1 TB SSD/NVMe | 在实测内存和运行量支持时扩展 |

系统优先 Ubuntu 24.04 LTS，使用支持 C++20 的 GCC 13 或相应 Clang、CMake 和 Python 环境。现有项目继续采用固定版本的第三方引擎。编译和运行命令见 README。 [项目 Quickstart](../../README.md#quickstart)

先在云端取一个相同数据日复测，记录同样的总耗时和峰值内存，再确定并发数量。服务器具体 CPU 型号、共享程度、SSD 吞吐和文件缓存会影响结果。

## 二、三种产品如何选择

| 产品 | 对本项目的适用性 | 需要确认的事项 |
| --- | --- | --- |
| 云服务器 | 适合稳定开发、SSH、长期 CPU 计算及独立数据盘 | 纯 CPU 配置报价、SSD 单价、带宽和关机后保留资源费用 |
| 容器云 | 适合按需开机、批量回放和模型实验，指南说明网络不单独收费 | 套餐中的 CPU/内存、持久存储挂载、停机后的存储费用 |
| 云桌面集群 | 适合成熟后的批量作业和统一调度 | CPU 队列权限、核时价格、计算目录配额、数据传输与软件环境 |

云服务器指南的配置截图中有“纯 CPU”选项，适合先索取 8 核/32 GB 和 16 核/64 GB 的报价。容器云指南给出 1 张 RTX5090、14 vCPU、120 GB 内存的示例套餐，标价为 2.98 元/小时，另显示 30 GB 本地系统盘。该套餐可作为费用参考，实际下单时应核对选中配置和优惠是否仍适用。

集群指南中的 N50R5 公共 GPU 队列，每张卡分配 8 个物理 CPU 核和 126 GB 内存，限制纯 CPU 作业；CPU 任务需先向平台确认可用队列。计算节点没有外网，应先在允许联网的环境中准备依赖与数据，再提交作业。家目录默认 1 GB，计算目录 `~/run` 默认 300 GB，扩大数据缓存需要确认配额。

## 三、本机完整日验证的实测依据

本次选用百度网盘 2026-07-12 的同源原始盘口和逐笔成交。选择这个较小的完整日，是为了先完成格式和账本链路验证。更繁忙的数据日需要另测峰值。实测机器为 Apple M5、16 GB 内存，Release 构建使用 AppleClang 21、`-O3 -DNDEBUG -std=c++20`。

| 阶段 | 耗时 | 峰值内存 |
| --- | ---: | ---: |
| 原始数据转换 | 308.38 秒 | 2.777 GiB |
| M0 行情回放 | 208.94 秒 | 0.069 GiB |
| M1 策略运行 | 14.29 秒 | 0.069 GiB |
| Python 独立对账 | 3.50 秒 | 0.142 GiB |

原始压缩文件合计 479.20 MB，标准化 NPZ 合计 1,142.07 MB，共 733 个分片。两侧分别处理 91,611,358 条逻辑事件，最终盘口与转换器保存的独立对照一致。策略的订单、成交、费用、仓位和权益经过 CSV 独立核对。 [验证记录目录](../../workspace/results/validation/baidu_2026-07-12/)

转换峰值内存测量包含 NumPy 排序和内存映射处理。回放程序的 Peak RSS 由程序内 `getrusage` 记录。M0 耗时包括前十档观察与统计，M1 耗时来自已有固定报价入口，两者分别用于相应运行计划。模型训练和未来 Alpha 特征计算需要增加自己的实测项。

## 四、按指南示例估算费用

以下金额采用容器云指南的示例价格，使用 30 天、720 小时作为一个计费月。计算资源只在运行的小时数内计入，存储按所列容量连续保留一个月计算。实际存储是按使用容量还是预留容量结算，需要在控制台确认。

- 示例计算资源为 2.98 元/小时。
- 共享存储和自定义镜像存储示例为 0.00048 元/GB/小时，即约 0.3456 元/GB/月。
- 500 GB 存储约 172.80 元/月，1,000 GB 约 345.60 元/月。
- 指南说明容器云共享网络不单独计费。

| 每月实际运行时间 | 计算费用 | 500 GB 保留一个月 | 合计 |
| --- | ---: | ---: | ---: |
| 40 小时 | 119.20 元 | 172.80 元 | 292.00 元 |
| 100 小时 | 298.00 元 | 172.80 元 | 470.80 元 |
| 200 小时 | 596.00 元 | 172.80 元 | 768.80 元 |

因此，按这组示例套餐和存储口径，小规模到较频繁研究可先按每月约 300—800 元估算。若计算资源持续开机 720 小时，仅计算费用就约 2,145.60 元；加 500 GB 存储约 2,318.40 元。自定义镜像、额外备份或更大容量按各自持续时长另计。

### 一轮多日任务大约花多少

按本次完整验证中转换、M0 回放、M1 策略和 Python 对账四项耗时相加，单日合计约 535.12 秒。若 304 个日期与该日运行量相同，串行总运行量约 45.19 小时。

把它作为容器资源运行时间的近似参考，按 2.98 元/小时计算约 134.66 元。若同一实例能以相同单任务速度并发 4 个日期，理想计算费用约 33.66 元。若云端单任务用时为本机 2 倍，上述计算费用也相应乘以 2。

这组外推包含一轮固定的验证流程，另需计入初次下载、特征生成、训练和额外策略组合。并发受 CPU、内存和存储吞吐共同约束。先以 7 天任务测得真实云端倍率，再预算一个月或整个研究区间。

下载应与实验解耦。同一数据版本只做一次标准化，特征按定义缓存，多个参数组合复用这些结果。本次网盘下载耗时记录在来源清单中，云端下载速度要另测。 [来源与下载记录](../../workspace/results/validation/baidu_2026-07-12/source_files.json)

### 云服务器与集群费用怎样比较

云服务器指南给出 RTX3090、10 vCPU、32 GB 内存的示例价格 3.30 元/小时，包月示例 1,162.50 元。两者仅计算资源的临界使用量约为每月 352 小时，磁盘和网络另外计算。该示例与容器套餐的 CPU、内存和 GPU 配置不同，需要按实际工作负载比较。

指南的云服务器出口流量单价有 1.00 元/GB 与 1.07 元/GB 两种表述，可先按这个区间估算，并向平台确认当前口径。固定 5 Mbps 示例为 0.335 元/小时，持续一个月约 241.20 元，理论传输上限约 0.625 MB/s。大文件传输应单独测量，不宜用这个小带宽配置估算批量迁移速度。

云服务器 SSD 云盘单价、纯 CPU 套餐价格，以及集群 CPU 队列核时价格，三份指南都没有提供可直接使用的完整报价。对应总费用分别按“主机小时费 + 磁盘 + 网络”和“申请核数 × 运行小时 × 核时价 + 存储/传输”核算。

## 五、开机与存储安排

第一批保留 7—30 天热数据，使用 300—500 GB SSD，标准化与特征完成后复用缓存。原始档案在网盘保留来源，云端按研究日期分批预取。若需要长期保留全年原始文件、NPZ、特征和全部逐笔实验记录，再按真实容量扩展到 1 TB 或更大。

容器运行数据放在持久化共享存储中。云服务器按指南选择合适的关机模式，并分别核对计算、云盘和网络的停止计费条件。集群采用提交后自动结束的批处理方式，按申请资源计算费用。具体 GPU 和格式选择见单独说明。 [GPU 与 Parquet 选择](gpu_and_parquet.md)
