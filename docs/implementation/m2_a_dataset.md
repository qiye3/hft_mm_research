# 高频研究数据集

当前研究覆盖 2025-05-09 至 2026-10-21，共 531 天。官方普通成交和历史快照经过 Data 标准化，Features 使用交易所时间加 20ms 的可见时钟，每 100ms 保存一条基础观测。

Features 每列保存全部日期，Factors 在完整 100ms 输入上计算秒级窗口，每个 UTC 整秒输出。300 个非 OFI 因子使用 Float64，默认要求窗口内 80% 观测有效。跨午夜连续滚动，缺失位置保留为空。

Targets 使用独立配置和入口，每秒生成未来 1s、10s、60s、180s、300s 标签。按周期和日期保存，支持跨日，主单位为 bps，并保留 ticks 和 USDT。未来完整区间须通过盘口质量检查，来源切换构成明确边界。

完整配置、目录、调用顺序、评价和模型入口见[研究包指南](research_package.md)。
